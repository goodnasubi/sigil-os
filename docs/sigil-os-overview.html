sigil-os は、ほかの OS と
何が違うのか

sigil-os は、プログラミング言語 Sigil で書かれた OS 本体です。目指すのは汎用 OS の置き換えではなく、「信用しなければならない部分」をできるだけ小さくし、その範囲をすべて列挙できる OS です。このページでは、その違いと優位性を4枚の図で説明します。

S

ひと言でいうと ―― 一般的な OS ではカーネル全体が事実上の信頼対象になりますが、sigil-os では信頼が必要なのは 原始操作（raw.*）とローダーなど、ごく限られた部分だけ。残りはすべて、言語の型と効果による通常の検査が効く trust none の世界で実装します。

図 2

信頼範囲の比較 ― 何を信用しなければならないか

バーの色つき部分が「正しさを信用するしかない範囲」のイメージです（規模の比率を表す実測値ではありません）。設計方針の違いとして読んでください。各 OS 名やバーをクリックすると、方針の違いがパネルに表示されます。

一般的な OS（Linux 等）カーネル全体が事実上の信頼対象
Rust 製 OS（Redox、Tock 等）メモリ安全性は言語で得られる
seL4 のような形式検証済みカーネル正しさを「証明」で保証する
sigil-os言語の検査で境界を小さく保ち、証明は将来に備える
信用するしかない範囲言語の検査が効く／対象外の範囲
