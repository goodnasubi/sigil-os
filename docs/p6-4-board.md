# P6-4 組み込み実機の構成（ADR 0054 決定 7）

P6-4 の対象は x86-64 の組み込み実機 1 構成である。本書は、その構成を **要件として固定**し、
実機の機種を **選定**してまとめる（下の「機種」）。**実機は未入手で、購入・発注は行っていない**。
実機の購入・発注は、人間の負担と費用に直結するため、所有者の判断に委ねる。

## 固定する構成（要件）

実機の機種を問わず、次を満たす 1 構成を P6-4 の対象とする。これは P6-1 の起動契約
（[boot-contract.md](boot-contract.md)）と、P6-4 で観測する機器 1 種から導いた。

| 項目 | 固定する値 | 理由 |
|---|---|---|
| CPU | x86-64（64 ビットのロングモード） | ADR 0054 決定 7 |
| ファームウェア | UEFI（64 ビット）。Secure Boot は無効にできること | 起動契約。試験用のローダーは未署名 |
| 起動媒体 | USB 接続のストレージ（USB メモリ）。`make usb` が作る `build/sigil-os-usb.img` を書き込む | 組み込み実機で入手・書き換えが容易。QEMU でも同じ経路を近似できる（`make check-p6-4`） |
| 起動順序 | UEFI のブートメニューで USB を最優先にする。フォールバックの `\EFI\BOOT\BOOTX64.EFI` を使うため、ブートエントリの登録は要らない | 起動契約 |
| メモリ | 256 MiB 以上 | 試験用カーネル窓 `[0x02000000, 0x02200000)` と UEFI のメモリマップを収めるため |
| 観測する機器 1 種 | **COM1 の 16550 互換 UART**（I/O ポート `0x3f8`、115200 baud、8N1） | 起動契約がシリアル出力を COM1 に固定している。専用のドライバーなしで、機器への入出力を観測できる |
| 観測の取得 | 実機の COM1（RS-232 の D-Sub 9 ピンまたはヘッダー）を、USB-シリアル変換などでホストに接続して記録する | 実機には画面を使わない |
| 不要なもの | PCI の VMware 機器（PVSCSI・VMXNET3）。ESXi。ネットワーク | P6-4 は実機そのものを検証環境にする |

実機の COM1 が I/O ポート `0x3f8` の 16550 互換でない場合（メモリマップドの UART だけを持つ機種など）は、
その機種は本構成に **合わない**。機種の選定ではこの点を最初に確かめる。

## 機種の選定の進め方（選定前の提案。記録として残す）

次の順で絞り込むことを提案する。機種名は、この環境からベンダーの公式資料を確認できていないため、
ここでは挙げない。所有者が購入を決める前に、各条件を公式資料と実機で確かめる必要がある。

1. **必須（上の表を満たす）**: x86-64、UEFI（Secure Boot を無効にできる）、USB から起動できる、COM1 が
   I/O ポート `0x3f8` の 16550 互換（レガシー COM ポートを持つ、または BIOS 設定で COM1 に割り当てられる）。
2. **強く望ましい**: シリアルがボード上の D-Sub 9 ピンまたはヘッダーに出ている（USB-シリアル変換を挟める）。
   メモリ 256 MiB 以上は事実上どの機種でも満たす。
3. **望ましい**: 産業用・組み込み用として長期供給される。BIOS 設定でシリアルのリダイレクトを無効にできる
   （ファームウェアがシリアルを占有すると、起動ログと混ざる）。

提案する進め方:

- 所有者が、上の必須条件を満たす候補を 1〜2 機種に絞る（予算・入手性による）。
- 候補ごとに、公式資料で「UEFI」「Secure Boot の無効化」「COM1 の I/O ポート」を確かめる。
- 決まった機種を、本書の「固定する構成」の下に「機種」として追記する（別 PR）。
- 実機が届いたら、[p6-4-verification.md](p6-4-verification.md) の「実機での手順」を実施して記録する。

## 機種（選定。Issue #11）

**ASRock Industrial iBOX-225H**（iBOX Ultra 200 シリーズ、ファンレス組み込みボックス PC）を、P6-4 の実機 1 構成として選定する。
同シリーズの iBOX-255H も、確認した入出力は同じである。選定の根拠は、ベンダー公式の
[iBOX Ultra 200 Series User Manual Version 1.0（2026 年 1 月）](https://download.asrock.com/IPC/Manual/iBOX-255H.pdf)
だけである（実機は未入手で、動かして確かめたことはない）。

| 要件（上の表） | マニュアルの記載 | 状態 |
|---|---|---|
| x86-64、UEFI | Intel Core Ultra 5 225H / Ultra 7 255H。ASRock Industrial UEFI。F2 または Delete で設定画面に入る | 記載あり |
| Secure Boot を無効にできる | UEFI の Security 画面に Secure Boot の設定項目がある。無効化の具体的な操作は記載がない | **実機で確認** |
| USB から起動できる | Boot 画面で起動優先順位を設定できる。USB メモリ起動の明示的な記載はない | **実機で確認** |
| COM1 が I/O ポート `0x3f8` の 16550 互換 | COM ポートが 1 つ（RS-232/422/485）。UEFI の Super IO Configuration で COM1 の種別（RS232 / RS422 / RS485）を選べる。Super IO は Nuvoton。**I/O アドレスと 16550 互換の記載はない** | **実機で確認（最重要）** |
| シリアルのリダイレクト | UEFI 設定に Console Redirection の項目は見当たらない | 実機で確認 |
| メモリ 256 MiB 以上 | 本体は DDR5 SO-DIMM（1.1V）× 2。**ベアボーンで、メモリ・SSD は付属しない**（別に用意する） | 記載あり |

実機に合わせて注意する点:

- COM ポートの端子は、マニュアルのピン表（RS-232: 1 DCD、2 RXD、3 TXD、4 DTR、5 GND）から、**5 ピンのコネクタ**であり、D-Sub 9 ピンではない。USB-シリアル変換（RS-232 レベル）を接続するには、このピン配置に合う変換ケーブルが要る。
- COM の種別は UEFI で **RS232** にする（RS422・RS485 にしない）。
- 起動に必要なメモリは DDR5 SO-DIMM 1 枚（本構成が要る 256 MiB を大きく超える容量で足りる）。SSD は不要（USB メモリから起動する）。
- 出荷時の UEFI（ファームウェア）の版は、マニュアルに記載がない。**実機の入手後に UEFI の画面で確認し、本書と [p6-4-verification.md](p6-4-verification.md) に記入する。**

この選定は、実機での確認で次のいずれかに当たった場合は **差し替える**:

- COM1 が I/O ポート `0x3f8` の 16550 互換でない（`0x3f8` に固定できない、メモリマップドのみ、など）。
- Secure Boot を無効にできない。
- USB メモリから `\EFI\BOOT\BOOTX64.EFI` で起動できない。

購入・発注は行っていない（所有者の判断）。購入の前に、販売元またはベンダーへ、COM1 の I/O アドレスと 16550 互換を問い合わせて確かめることを勧める。
