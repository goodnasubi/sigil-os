# P6-1 起動契約

対象は x86-64 の ESXi VM と UEFI。ブート ISO の EFI システムパーティションを
UEFI が開き、`\EFI\BOOT\BOOTX64.EFI` が同じボリュームの
`\kernel.elf` を読む。シリアル出力は仮想 COM1（I/O 0x3f8、16550 互換、
115200 baud、8N1）。試験 ISO は未署名のため Secure Boot を無効にする。

## ELF

ELF64 little-endian、System V OSABI、EM_X86_64、ET_EXEC。ファイルは最大
2 MiB、プログラムヘッダーは最大 32 個。各 `PT_LOAD` の仮想アドレス
と物理アドレスは一致し、範囲 `[0x02000000, 0x02200000)` に収める。
全セグメントを重なりなく配置し、入口アドレスを実行フラグがある
セグメントのファイルデータ内に置く。ローダーは範囲を検査し、
バイトをコピーして残り（BSS を含む）をゼロにする。注記、プログラムヘッダー、
GNU スタックの記述は読み飛ばす。動的リンク、再配置、TLS は契約外。
セグメントのフラグは入口の検査に使う。ハードウェアページの R/W/X 分離は行わない。

## 引き渡し

- ファイルを閉じてからメモリマップを取得する。マップ取得と
  `ExitBootServices` の間に他のファームウェア API を呼ばない。
  マップキーの競合では取得と終了を一度やり直す。
- 成功後にシリアルへ `ExitBootServices OK` を出し、ELF 入口に
  SysV AMD64 の関数呼び出しで渡す。RDI が `const struct boot_info *`、
  RSP は専用の 64 KiB スタック上で入口の `RSP % 16 == 8`。
  割り込み（IF）と方向フラグ（DF）はクリア、RBP はゼロ。他のレジスター値は未規定。
  UEFI のロングモードと当該領域の恒等マッピングを引き継ぐ。
  CPU の表や拡張レジスターの初期化は保証しない。入口はレッドゾーンを使わず、
  最初の試験は汎用レジスターのみ使う。
- [boot_info](../boot/contract.h) は little-endian の固定レイアウト。
  v1 は 40 バイトで、版・構造体サイズ・メモリマップのアドレスとサイズ・
  UEFI 記述子のストライドと版・ゼロの予約フィールドを渡す。マップは
  最大 128 KiB。記述子を読む場合は渡されたストライドで進める。
- ローダーのイメージはメモリマップと起動情報、専用スタックを保持する。
  カーネルは起動情報とマップを読み取り専用で借用し、参照している間は
  ローダーのイメージを再利用しない。専用スタックの領域は切り替えまで保持する。
  ファームウェアの Boot Services は引き渡し後に使用できない。
- 入口は復帰しない。復帰時、対象外 ELF や起動失敗時は、マスク可能割り込みを
  無効にして `hlt` を繰り返す。不正な起動情報は受け手で検査して停止する。
  試験用の受け手は版・サイズ・予約フィールド・マップのアラインメント、
  長さ、範囲のオーバーフロー、記述子の版とストライドを検査する。

## ESXi での試験手順

1. x86-64 ESXi に UEFI VM を用意する。Secure Boot を無効にし、仮想
   CD/DVD と仮想シリアルポート COM1 を追加する。シリアルの出力先は
   各試験で別のファイルに設定する。ESXi の版とビルド、VM の互換性レベル、
   EFI と Secure Boot の設定、割り当てた CPU とメモリ、仮想 CD/DVD と
   COM1 の接続構成を記録する。
2. `make images` で作成した `build/probe.iso`、`build/bad-elf.iso`、
   `build/bad-info.iso` を各回の仮想 CD/DVD に接続して EFI 光学メディア
   から起動する。シリアルを保存し、[検証記録](p6-1-verification.md)
   の各ケースと照合する。
3. P6 出力に対応した Sigil の完全 SHA と `Cargo.lock` を固定し、
   `cargo build --locked --release` で生成器をビルドする。確保を使わない
   プログラムから ELF を出力し、ローダーとパッケージ化する。Sigil 成果物で
   入口到達、起動情報の版と検査結果、拒否時の停止を確認し、ビルドコマンド・
   ELF の検査結果・シリアル出力を保存する。
